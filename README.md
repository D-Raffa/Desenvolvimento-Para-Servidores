# Desenvolvimento para Servidores

Este repositório reúne as atividades, exercícios e projetos desenvolvidos durante a disciplina de **Desenvolvimento para Servidores**.

## Objetivos

- Aplicar os conceitos de Programação Orientada a Objetos (POO) em Java;
- Desenvolver sistemas web utilizando PHP;
- Praticar a criação de classes, métodos e estruturas orientadas a objetos;
- Aprimorar a lógica de programação e o desenvolvimento back-end.

##  Tecnologias

- Java
- PHP
- HTML
- CSS
- MySQL
